## ⚡ What Is This?

A curated collection of **design-focused agent skills** for frontend and UI/UX work: Tailwind systems, dark UI, motion, mobile-first layouts, high-end visual polish. This repo doesn't store the skills. It lists the best ones and gives you a single command block that installs all of them from their original authors' repos.

> **These aren't prompts. These are agents with taste.**

<img src="https://user-images.githubusercontent.com/73097560/115834477-dbab4500-a447-11eb-908a-139a6edaec5c.gif" width="100%">

## 🚀 Quick Setup

Copy the whole block, paste it into your terminal from your project root, and answer the CLI's prompts. Uses the [`skills`](https://skills.sh) CLI (needs Node.js).

```bash
npx skills add emilkowalski/skills --skill animate --skill animation-vocabulary --skill apple-design --skill ask-sonner --skill emil-design-eng --skill find-animation-opportunities --skill improve-animations --skill pick-ui-library --skill prototype --skill review-animations
npx skills add Leonxlnx/taste-skill
npx skills add sickn33/agentic-awesome-skills --skill angular-ui-patterns --skill antigravity-design-expert --skill frontend-ui-dark-ts --skill magic-ui-generator --skill mobile-design --skill radix-ui-design-system --skill stitch-ui-design --skill tailwind-design-system --skill ui-ux-designer --skill ui-visual-validator
npx skills add anthropics/skills --skill frontend-design --skill canvas-design --skill theme-factory --skill brand-guidelines --skill web-artifacts-builder
npx skills add vercel-labs/agent-skills --skill web-design-guidelines
npx skills add google-labs-code/stitch-skills --skill design-md
npx skills add remotion-dev/skills --skill remotion-best-practices
npx skills add ibelick/ui-skills --skill ui-skills
npx skills add nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max
npx skills add https://uizze.sh/
```

> 💡 Each command asks which agent(s) to install for, then places the skills where that agent auto-detects them. Want just one? Run only that line, or copy the single skill from the index below.

## 🤝 Contributing

Found a skill worth listing?

1. Fork the repo
2. Add the skill to the Skill Index and its install line to the master command in Quick Setup
3. Open a PR saying what the skill does and where it's installed from

Good skills are **focused**, **opinionated**, and **actionable**, not generic advice.
